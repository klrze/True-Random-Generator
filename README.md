# Statistical Unpredictability via Environmental Sensors
# Official STEM Paper: [STEM Paper](https://drive.google.com/file/d/1aTYWe2ziNjIF96YkrC1IfBKpYfWaqG9G/view?usp=sharing )
# Description
This project generates random numbers derived from the environment using readings from Arduino sensors. The Arduino communicates with the Spring Boot program via serial port. From the Spring Boot program, data is then persisted into a PostgreSQL database. The data from the database is analyzed using a Python program.
# Software Used
- Java: Spring Boot, Intellij IDEA
- Python: PyCharm
- PostgreSQL: Supabase
- Arduino Uno: Arduino IDE
